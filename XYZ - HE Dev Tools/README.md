# Dev

Developer reference for the apps and drivers in this repo. Nothing here is installed by HPM.

- **Hubitat-App-UI-Style-Guide.md** - App UI layout, spacing, navigation and dark mode guidance from gopher.ny (Hubitat), started from the Reolink Integration. Work in progress; update it when he sends a newer version.
- **HubitatAppUiTemplate.groovy** - Drop-in Groovy for a new app's UI: status banner, two-column main page, dark mode, link-only Add/Edit pages with Cancel/Save, logging popup, Help & Support, Tips page. Updated to Reolink 1.6.17 / Sofabaton 1.1.6.
